# Trigger agents from Slack

Once an agent's Slack app is installed, teammates can talk to that agent directly from Slack without opening the web app.

**Before you start:** the agent's Slack app must be installed and connected. If it isn't yet, see **[Slack integration setup](/deploy/slack)**.

## How your team uses it

### Starting a conversation

There are two ways to invoke the agent:

1. **Mention its bot in a channel.** Add the bot to the channel, then mention it with a request.
2. **Send the bot a direct message.** The message starts a private conversation with that agent.

Every Slack thread maps to a dedicated **auxilia** thread, so the agent remembers the conversation context.

### Having the conversation

Messages stream into Slack as the agent responds. Tool activity can also be shown inline when callouts are enabled on the Slack connection.

Because the Slack thread is persistent, you can come back a day later, ask a follow-up, and the agent will pick up exactly where you left off.

### Approving sensitive actions

If the agent wants to run a tool that you've configured as **needs approval**, such as updating a HubSpot deal or creating a GitHub pull request, it won't just do it. Slack posts a message with **Approve** and **Reject** buttons:

- **Approve** → the agent runs the tool and continues
- **Reject** → the agent is told no, and decides what to do next (often, explaining it needs a different approach)

This is the same approval flow as in the web UI, just surfaced where the team already lives.

## Who can use it

**Every Slack user needs an auxilia account with the same email address as their Slack profile.** When someone sends a message, **auxilia** looks up their Slack email and matches it to the workspace user directory. If there's no match, the bot replies with a gentle message telling them to sign up in **auxilia** first.

The bot accepts requests only from users who have permission to use its agent.

## Good ways to set this up for a team

A few patterns that work well:

- **One focused agent in a team channel.** For example, `#sales-help` can have a CRM agent that channel members mention when needed.
- **Several clearly named agent bots.** Install only the relevant agents in each Slack workspace so teammates can identify the right specialist.
- **Direct messages for sensitive work.** Users can message the appropriate agent bot privately.

## Reusing an agent across multiple threads

Each Slack thread has its own memory. Start a new message or direct-message thread for a fresh conversation with the same agent.

## Troubleshooting

**"I mentioned the bot but nothing happened"**: the agent bot must be invited to the channel. Type `/invite @bot-name` or add it from the channel settings.

**"The bot said it doesn't recognize me"**: your Slack email doesn't match an account in **auxilia**. Sign up in the web app with the same email you use in Slack, then try again.

**"I don't have permission to use this agent"**: ask an agent administrator to grant you access on the agent's permissions page.
